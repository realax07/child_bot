# privacy

## ADDED Requirements

### Requirement: Данные только на нашем сервере (FR-25)

Все данные пользователей MUST храниться только на нашем сервере: SQLite-файл и бэкапы локально рядом с ботом (решения 26.10 №6, №7). Передача данных внешним сервисам, сторонней аналитике и любым облачным хранилищам SHALL NOT допускаться.

#### Scenario: Проверка хранилища
- **WHEN** бот работает в штатном режиме
- **THEN** все записи (users, sleep_events, settings) и их бэкапы находятся на нашем сервере; исходящих передач данных пользователей во внешние системы нет
