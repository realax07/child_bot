# API-матрицы на эндпоинт (reference для test-case-design)

Обязательные чек-таблицы для REST API (источник: api-test-suite-builder,
claude-skills; адаптация под наш стек FastAPI: 401/403/422). Для КАЖДОГО
нового/измененного эндпоинта — прогон обеих матриц; неприменимая строка
помечается «N/A (основание)».

## Auth-матрица (каждый авторизованный эндпоинт)

| # | Кейс | Ожидание |
|---|---|---|
| A1 | Без заголовка авторизации | 401 |
| A2 | Невалидный формат токена | 401 |
| A3 | Валидный токен, чужая роль | 403 |
| A4 | Истекший токен | 401 |
| A5 | Токен удаленного/разжалованного пользователя | 401 |
| A6 | Валидный токен, валидная роль | 2xx |
| A7 | Изоляция: чужой ресурс по id | 403/404 |

A7 — проверка «пользователь B не достает ресурс пользователя A прямым
вызовом API» (не только отсутствие кнопки в UI).

## Input-validation матрица (каждый POST/PUT/PATCH с телом)

| # | Кейс | Ожидание |
|---|---|---|
| I1 | Пустое тело `{}` | 422 |
| I2 | Пропуск каждого обязательного поля (по одному) | 422 |
| I3 | Неверный тип (строка вместо числа) | 422 |
| I4 | Границы: min-1 | 422 |
| I5 | Границы: min | 2xx |
| I6 | Границы: max | 2xx |
| I7 | Границы: max+1 | 422 |
| I8 | null вместо обязательного поля | 422 |
| I9 | SQL-инъекция в строковом поле | 422 или 2xx (санитизировано) |
| I10 | XSS-нагрузка в строковом поле | 422 или 2xx (санитизировано) |
| I11 | Дубликат уникального ресурса | 409/422 (по спеке) |

## Дисциплина

- Матрицы — минимальный базис, не потолок: поверх добавляются классы
  (negative-classes.md) и комбинации (decision-tables-pairwise.md).
- Для sanitize-поверхности (I9/I10) ожидание фиксировать по спеке домена:
  «отклонить» или «принять и обезвредить» — разные ассерты.
- Кейсы из матриц трассируются к FR/NFR эндпоинта как обычные TC.
