  - Зона: `src/services/state.py`, `src/handlers/common.py`, `tests/test_state.py`
  - Сделать: состояние ребёнка выводится из последнего события (нет событий/wake → бодрствует, sleep → спит); клавиатура строится по состоянию: ровно одна событийная кнопка («😴 Заснул» или «☀️ Проснулся»), плюс «↩️ Отменить последнее».   - Зона: `src/handlers/events.py`, `src/services/event.py`, `tests/test_events_now.py`
  - Сделать: callback `event:sleep`/`event:wake` → меню §7.10 («🕐 Сейчас» / «⏪ Ввести время вручную»); «Сейчас» создаёт событие с текущим временем, переключает меню, отвечает §7.5/§7.2 (строка «Крайнее пробуждение» из настройки; окно в §7.2 не выводится). Guard колбэка (design D5): перед созданием события состояние перепроверяется по БД; нажатие устаревшей кнопки, противоречащее актуальному состоянию (например, «😴 Заснул» из старого сообщения, когда ребёнок уже спит), игнорируется — событие не создаётся, answerCallbackQuery + перерисовка актуальной клавиатуры. `sleep_type` при записи не вычисляется (design D6).
  - Трассировка: FR-7, FR-8, FR-15; design D2, D5, D6.
  - Готовность: юнит-тесты: sleep-событие создано с фактическим временем, is_backfilled=0; ответ §7.2 без строки окна; меню переключилось; нажатие «😴 Заснул» из устаревшей клавиатуры при спящем ребёнке — записи нет, клавиатура перерисована в актуальное состояние (guard, F-3 review-001).
- [x] 2.4 Кнопка «↩️ Отменить последнее» `[P]`

  - Трассировка: FR-21; design D12.
  - Готовность: юнит-тесты: после отмены засыпания ребёнок снова бодрствует, запись удалена; отмена при пустой БД не изменяет данные.
