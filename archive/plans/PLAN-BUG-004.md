## Симптом и root cause (кратко)

«Бодрствование общее» = окно страницы 24:00 − покрытие сном внутри окна → 20:02
вместо (20:33 − 08:00) − 1:58 = 10:35. Будущие часы страницы посчитаны
бодрствованием; база — day_start вместо подъёма; ночной хвост 06:00–08:00 вычтен.
Формула продакта утверждена 2026-10-31 (см. карточку).

## Изменение (одна функция + точка вызова)

- `src/services/calculation.py` `day_facts_lines`: строка «Бодрствование общее»:
  - база = «Подъем» (конец последнего ночного отрезка страницы в утреннем окне,
    по тем же правилам, что факт «Подъем»); нет подъёма → day_start страницы;
  - конец = момент расчёта `now_local`; если последний интервал — незакрытый
    НОЧНОЙ сон (идёт ночь) → конец = начало этого сна;
  - вычитается только покрытие ДНЕВНЫМ сном, пересекающее [база; конец]
    (включая незакрытый дневной сон — до конца = now_local);
  - ночное покрытие не вычитается (в базе от подъёма его нет);
  - отрицательное значение → 0 («Бодрствование общее: 0 мин»).
- Зоны расчета/склейки/классификации больше не трогаются (фикс только в одной
  строке вывода + хелпер расчёта).
- Спек-дельта: diary-events «Сводка событий дня» + backfill-input FR-19 —
  переформулировать «Бодрствование общее» (продуктовое решение Марии 2026-10-31,
  не правка под код; правит ПМ вместе с задачей).
