## Что строим (итог пакета)

- **Настройки (§5, §7.16–7.19):** экран ⚙️ Настройки (12 параметров,
  группировка §7.16), изменение значения через диалог §7.17 → успех §7.18 /
  ошибка §7.19; каждое изменение — запись в `settings_history` (§5.1:
  user_id, key, старое, новое, когда).
- **История (§4.8, PB-5):** кнопка «📊 История за неделю» — сводка за 7 дней
  (§7.20: бодрствование, дневной сон, ночь, отметка ✓/⚠️) + за сегодня;
  «нет данных» — §7.21, устаревшие данные — §7.22.
- **Справка и безопасность:** /help (§7.28), /delete_all с подтверждением
  (§7.26–7.27) — удаляет ВСЁ пользователя безвозвратно.
- **PB-1:** парный ввод задним числом — один диалог спрашивает и засыпание,
  и пробуждение (оба формата времени), единая проверка конфликтов; если
  засыпание уже записано — спросить только пробуждение.
- **PB-2:** пресеты времени в диалогах ввода («вчера 21:00»-стиль и кнопки
  быстрых пресетов) — дешевая часть, Web App не делаем.

## Решения (зафиксировано ранее, не спрашиваем)

- Роль наблюдателя: чтение без ограничений, UI смены роли — не делаем (ОВ-5).
- settings_history-таблица уже в схеме пакета 1 — используется, миграций нет.
- Ночная рекомендация — по ОВ-4.2 (конкретное время, ≥12 ч 10 мин); формула
  бодрствования — BUG-004; форма сводки — PB-3. Ничего из этого не меняем.
- Техдолг пакета 2 (раздел «Техдолг пакета 2» бэклога) — убирается в волну
  рефакторинга этого пакета: дубли хелперов, owner_users SQL, мёртвая
  total_wake, nap_window_text в §7.5-ветке.

## Волны (Флоу 1)

### Волна 1. Настройки (SettingsService + экраны §7.16–7.19)
Экран настроек, диалог изменения, валидация значений (форматы `5:20`/`5ч20м`),
запись в settings_history, хелперы-дубли из техдолга (свод источников дефолтов).

### Волна 2. История (PB-5 + §4.8/§7.20–7.22) и PB-2 пресеты
Кнопка «📊 История за неделю»: 7 дней + сегодня, ✓/⚠️ по границам, §7.21/7.22.
Пресеты времени в диалогах ввода задним числом (PB-2).

### Волна 3. PB-1 парный ввод + /help + /delete_all
Парный диалог засыпание+пробуждение (PB-1); /help §7.28; /delete_all §7.26–7.27
(подтверждение отдельным шагом, удаление всех данных пользователя).

### Волна 4. Smoke пакета 3 + финальная уборка
Сквозной сценарий «неделя с настройками»: /start → события недели → история →
изменение настройки → settings_history запись → /help → /delete_all. Уборка
миноров из техдолга.

## Открытые вопросы продакту (ОВ-5)

- ОВ-5.1 (PB-1 формат парного ввода): одним сообщением «13:40 15:15» или
  двумя шагами диалога («Когда заснул?» → «Когда проснулся?»)? Рекомендация
  ПМ: двумя шагами — меньше ошибок ввода, один конфликт-чек на пару.
- ОВ-5.2 (PB-2 пресеты): какие кнопки-пресеты нужны в диалоге ввода?
  Рекомендация: «Вчера 21:00», «Вчера 08:00», «−15 мин», «Сейчас».
- ОВ-5.3 (/delete_all): подтверждение одной кнопкой «Да, удалить всё» или
  текстом-паролем? Рекомендация: отдельная кнопка подтверждения (§7.26).

Базовые волны стартуют без паузы; зависимые пункты — WAITING_PRODUCT.
