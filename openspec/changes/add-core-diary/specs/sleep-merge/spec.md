# sleep-merge

## ADDED Requirements

### Requirement: Автосклейка коротких пробуждений (FR-13)

Пробуждение короче порога склейки MUST не разрывать сон: смежные интервалы объединяются в один сон, короткое пробуждение не создаёт отдельного периода бодрствования (ТЗ §4.3). Расчёт — на лету (см. core-storage, FR-3).

#### Scenario: Склейка
- **WHEN** записаны интервалы: сон 13:00 → 14:00, бодрствование 14:00 → 14:15, сон 14:15 → 15:00, порог 20 мин
- **THEN** расчётные интервалы сна: один сон 13:00 → 15:00, бодрствование за период не учитывается

#### Scenario: Пробуждение длиннее порога
- **WHEN** пробуждение между двумя снами длится 25 мин при пороге 20 мин
- **THEN** интервалы SHALL NOT склеиваться: два отдельных сна и период бодрствования 25 мин

### Requirement: Порог склейки из настроек (FR-14)

Порог склейки MUST браться из `settings` пользователя (дефолт 20 мин, ТЗ §5); изменение порога меняет результат склейки при следующем расчёте без перезаписи событий.

#### Scenario: Порог из settings
- **WHEN** у пользователя порог склейки установлен 30 мин и записано пробуждение 25 мин
- **THEN** смежные сны склеены
