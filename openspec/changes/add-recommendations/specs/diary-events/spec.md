# diary-events

## ADDED Requirements

### Requirement: Окна сна в подтверждениях отметок (FR-38; §7.2–7.4 в ред. PB-3)

Подтверждения «✅ Пробуждение записано…» (стандартный/ранний/поздний подъём) и успешный ввод задним числом MUST содержать: факт (строка события) + строку окна дневного сна + сводку фактов дня PB-3 без изменений, включая «Бодрствование общее» по формуле BUG-004. Подавление окон из волны 6 снимается. Окно MUST считаться от фактического подъёма через CalculationService, не хардкодом. «Крайнее пробуждение: …» в подтверждении засыпания SHALL NOT возвращаться (решение 29.10).

#### Scenario: Крайнее пробуждение не возвращается
- **WHEN** родитель отметил «😴 Заснул» → «🕐 Сейчас»
- **THEN** ответ содержит подтверждение и сводку PB-3, без строки «Крайнее пробуждение: …»

#### Scenario: Пробуждение стандартного дня
- **WHEN** подъём 08:00 и родитель отметил «☀️ Проснулся» → «🕐 Сейчас»
- **THEN** ответ содержит «✅ Пробуждение записано в 08:00.», «Окно дневного сна: 13:20–14:00.» и сводку PB-3

#### Scenario: Ранний подъём
- **WHEN** подъём 07:00
- **THEN** ответ §7.3: подтверждение + совет растянуть бодрствование до 13:00 + окно 12:20–13:00 + якоря 15:30/22:00 + сводка PB-3

#### Scenario: Поздний подъём
- **WHEN** подъём 09:00
- **THEN** ответ §7.4: подтверждение + окно 14:20–15:00 + предупреждение «разбудить не позже 15:30» + сводка PB-3

#### Scenario: Сводка PB-3 не изменилась
- **WHEN** родитель вводит событие задним числом
- **THEN** сводка фактов дня идентична волне 6 пакета 1 (факты PB-3 + «Бодрствование общее» BUG-004), к ней добавлена только строка окна
