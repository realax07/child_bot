# settings-data

## ADDED Requirements

### Requirement: Дефолтные настройки (FR-23)

При `/start` MUST создаваться 13 параметров со значениями по умолчанию (ТЗ §5 + решение 26.10 №1): 12 параметров ТЗ (мин./макс. бодрствование до дневного сна 5:20/6:00, крайнее пробуждение 15:30, целевой уход 22:00, крайний уход 22:30, границы бодрствования 12,0/12,5 ч, напоминание заранее 15 мин, начало дня 06:00, порог склейки 20 мин, границы ночи 19:00–07:00, глубина ввода 3 дня) плюс настройка «целевая длительность дневного сна» = 1 ч 30 мин.

#### Scenario: Создание дефолтов
- **WHEN** новый пользователь прошёл `/start`
- **THEN** в `settings` для его user_id существуют все 13 параметров со значениями по умолчанию

### Requirement: Хранение и чтение настроек (FR-24)

Настройки MUST храниться в `settings` на каждого пользователя (ключ user_id, ТЗ §5, §9.3) и MUST читаться сервисами при расчётах (разметка, склейка, глубина ввода). UI изменения настроек и `settings_history` SHALL NOT входить в этот пакет (Пакет 3); в пакете настройки изменяются только данными (seed/миграция).

#### Scenario: Настройка влияет на расчёт
- **WHEN** у пользователя порог склейки отличен от дефолта
- **THEN** расчёт склейки (FR-13) использует его значение, а не константу в коде
