# child_bot — Telegram-бот «Дневник сна ребёнка»

Персональный бот: отмечаете «😴 Заснул» / «☀️ Проснулся», бот считает бодрствование,
ведёт дневник и хранит всё локально на нашем сервере.

Пакет 1 «add-core-diary» (ядро дневника) — реализован: кнопки, ввод задним числом
(до 3 дней), склейка коротких просыпаний, отмена последней записи, роль «наблюдатель»,
13 настроек, приватность. Подсказки окон сна и напоминания — этап 2.

## Запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN="токен от @BotFather"      # обязателен
export BOT_DB_PATH="/путь/до/child_bot.db"  # опционально (дефолт: ./child_bot.db)
python -m src.main
```

Проверка без выхода в сеть: `BOT_TOKEN=stub python -m src.main --check`

## Тесты

```bash
python -m pytest tests/ -q     # 181 тест, включая сквозной smoke пакета 1
```

## Бэкап

```bash
bash scripts/backup_db.sh /путь/до/child_bot.db   # sqlite3 .backup, локально
```

## Приватность

База и бэкапы только на нашем сервере; наружу не отправляются (проверяется
тестом test_privacy.py). Токен бота — только в переменной окружения.
