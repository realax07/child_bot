# state-ui

## ADDED Requirements

### Requirement: Кнопки «📊 История за неделю» и «⚙️ Настройки» в меню (ТЗ §6, FR-42, FR-48)

Главное меню MUST содержать кнопки «📊 История за неделю» и «⚙️ Настройки» в ОБОИХ состояниях ребёнка (бодрствует/спит) — до этого пакета этих кнопок в клавиатуре не было. Тексты кнопок — дословно §6; нажатие маршрутизируется как `history:week` / `settings:show` и MUST NOT создавать события. Существующие кнопки (событие состояния, «⏰ Подсказка сейчас», «↩️ Отменить последнее») MUST NOT изменить поведение.

#### Scenario: Кнопки в обоих состояниях
- **WHEN** меню построено для бодрствующего и для спящего
- **THEN** в обоих случаях присутствуют «📊 История за неделю» и «⚙️ Настройки» с текстами дословно §6

#### Scenario: Нажатие не меняет дневник
- **WHEN** нажата «📊 История за неделю» или «⚙️ Настройки»
- **THEN** в sleep_events нет новых записей; событийная кнопка состояния сохранена
