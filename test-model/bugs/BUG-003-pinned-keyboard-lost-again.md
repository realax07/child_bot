# BUG-003: прибитые кнопки пропали повторно (регресс BUG-002)

- **Дата:** 2026-10-29 (вечер, доложила Мария)
- **Источник:** Мария: «опять отвалились кнопки прибитые»
- **Severity:** S2 (повторно блокирует повседневный ввод)
- **Связь:** регресс/рецидив BUG-002 (хотфикс 5ea513d, merge 53ecc7e)

## Факты на сервере (проверено 29.10 ~19:05 UTC)

- Процесс жив: PID 3443910, старт 17:15:58 UTC 29.10, рабочий каталог чист,
  main на 87712ee — хотфикс BUG-002 (5ea513d) в коде ЕСТЬ.
- В коде НЕТ ReplyKeyboardRemove и ForceReply (grep по src пуст) — сервер
  в принципе не может убрать reply-панель: клавиатура — свойство чата на
  клиенте, снимается только явной командой удаления.
- Лог: 7 старых traceback'ов NetworkError (утреннее падение, до старта
  текущего процесса); свежих ошибок в хвосте нет.

## Ответы Марии (29.10 вечер)

1. Кнопки убрались **еще вчера (28.10)** «просто в какой-то момент», совсем.
2. Пропали полностью; `/start` вернул панель.

## Анализ таймлайна (ключевое)

- Хотфикс BUG-002 влит только **28.10 19:28 UTC (22:28 МСК)** — весь вчерашний
  день Мария была на старой сборке БЕЗ постоянной панели. «Убрались вчера» —
  это и есть исходный BUG-002, не регресс.
- Текущая сборка с фиксом работает с 17:15 UTC 29.10; на ней засыпание 22:04
  МСК записано штатно, подтверждение пришло.

## Статус: ПОД НАБЛЮДЕНИЕМ (вероятно НЕ регресс)

- На фиксированной сборке сервер панель снять не может (нет remove в коде).
- Критерий закрытия: панель держится у Марии ≥1 день активного использования
  (события/отмены/заднее число) на текущей сборке.
- Если пропадет снова на ЭТОЙ сборке — реальный BUG-003: собрать клиент
  (iOS/Android, версию), точное действие-триггер, воспроизведение ПМ.
