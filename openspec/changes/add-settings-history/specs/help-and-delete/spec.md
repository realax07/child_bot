# help-and-delete

## ADDED Requirements

### Requirement: Справка /help (FR-53)

Команда /help MUST возвращать текст §7.28 дословно и быть доступна в любом состоянии (бодрствует/спит, внутри других диалогов). /help MUST NOT создавать события, менять состояние и настройки и MUST NOT прерывать открытые FSM-диалоги.

#### Scenario: /help в любом состоянии
- **WHEN** родитель отправил /help (ребёнок спит или бодрствует, до/после настройки)
- **THEN** ответ §7.28; состояние, события и настройки не изменены

### Requirement: Подтверждение /delete_all отдельной кнопкой (FR-54, решение продакта 01.11 по ОВ-5.3)

Команда /delete_all MUST сначала показать подтверждение §7.26 («Удалить все данные? Это действие необратимо.») с кнопками [Да, удалить всё]/[Отмена]. Удаление MUST выполняться только после явного нажатия кнопки в отдельном шаге (способ зафиксирован продактом 01.11; текст-пароль отклонён). Любой другой ввод MUST гасить состояние подтверждения без удаления.

#### Scenario: Подтверждение и удаление
- **WHEN** /delete_all → нажато «Да, удалить всё»
- **THEN** все данные пользователя удалены, ответ §7.27; повторный /start пересеивает 13 дефолтов

#### Scenario: Отмена
- **WHEN** /delete_all → «Отмена»
- **THEN** ничего не удалено, бот возвращается в меню без текста §7.27

### Requirement: Удаление всех данных пользователя (FR-54)

При подтверждении MUST удаляться ВСЕ данные пользователя — sleep_events, settings, settings_history, строка users — безвозвратно и только его собственные. После удаления бот MUST ответить §7.27; следующий /start начинает заново с seed дефолтов.

#### Scenario: Изоляция удаления
- **WHEN** подтверждено удаление пользователем A
- **THEN** данные пользователя B (события, настройки, история) остаются нетронутыми
