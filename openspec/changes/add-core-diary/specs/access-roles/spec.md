# access-roles

## ADDED Requirements

### Requirement: Роль «наблюдатель» — только чтение (FR-22)

Схема `users` MUST содержать поле роли (`role`: `parent` — дефолт, `observer` — решение 26.10 №5). Пользователь с ролью `observer` MUST иметь доступ к просмотру сводок (механизмы сводок появляются в пакетах 2–3) и SHALL NOT иметь возможность создавать события: нажатие кнопок событий «😴 Заснул» / «☀️ Проснулся» / «↩️ Отменить последнее» игнорируется с сообщением, что отметки недоступны. UI назначения роли SHALL NOT входить в этот пакет.

#### Scenario: Наблюдатель жмёт кнопку события
- **WHEN** пользователь с ролью `observer` нажимает «😴 Заснул»
- **THEN** событие не создано, бот сообщает о недоступности отметок

#### Scenario: Наблюдатель запрашивает данные
- **WHEN** пользователь с ролью `observer` обращается за сводкой за день
- **THEN** сводка показывается так же, как родителю (по мере появления механизмов сводок в пакетах 2–3)
