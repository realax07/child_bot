# paired-backfill

## ADDED Requirements

### Requirement: Парный ввод задним числом — два шага (FR-51, решение продакта 01.11 по ОВ-5.1)

Ввод сна задним числом MUST спрашивать ОБА времени двумя шагами диалога — «Когда заснул?» → «Когда проснулся?» (формат §4.4; решение продакта 01.11) — и создавать оба события сразу с ЕДИНОЙ проверкой конфликтов на пару: пробуждение позже засыпания и отсутствие пересечений пары с уже записанными событиями. Успех — подтверждение §7.14-стиля; конфликт — §7.13 с [Изменить]/[Отмена].

#### Scenario: Пара из двух шагов
- **WHEN** выбран ввод сна задним числом, введены засыпание 13:40 и пробуждение 15:15
- **THEN** созданы оба события, единая проверка конфликтов пройдена, ответ §7.14-стиля

#### Scenario: Конфликт пары
- **WHEN** пара пересекается с записанным событием или пробуждение не позже засыпания
- **THEN** ответ §7.13 с [Изменить]/[Отмена]; новых событий нет

### Requirement: Незакрытое засыпание — только пробуждение (FR-51)

Если засыпание уже записано и не закрыто, парный диалог MUST спрашивать только время пробуждения; дублирующее засыпание SHALL NOT создаваться. Проверка глубины ввода (§7.15) MUST применяться к обоим временям пары.

#### Scenario: Засыпание уже записано
- **WHEN** незакрытый сон 13:40 уже есть и родитель вводит пробуждение задним числом
- **THEN** спрашивается только время пробуждения; засыпание не дублируется

#### Scenario: Слишком давняя пара
- **WHEN** время засыпания пары старше предела глубины (§7.15)
- **THEN** пара отвергается с §7.15; событий нет
