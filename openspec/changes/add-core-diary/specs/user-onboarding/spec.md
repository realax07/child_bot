# user-onboarding

## ADDED Requirements

### Requirement: Часовой пояс пользователя (FR-4)

При `/start` часовой пояс пользователя MUST сохраняться в `users.timezone` из TG-профиля (первое приближение по ТЗ §8.2), и все ввод/вывод/разметка времени MUST выполняться в этом поясе.

#### Scenario: Время в поясе пользователя
- **WHEN** пользователь с сохранённым часовым поясом отмечает «😴 Заснул» в 22:10 по своему локальному времени
- **THEN** событие сохранено как 22:10 пояса пользователя, разметка день/ночь выполнена по локальному времени пользователя

### Requirement: Инициализация пользователя командой /start (FR-5)

Команда `/start` MUST: создать пользователя в `users` (при первом обращении), сохранить часовой пояс (FR-4), создать 13 дефолтных настроек (см. settings-data, FR-23), установить состояние «бодрствует» и отправить текст ТЗ §7.1. При повторном `/start` повторная инициализация настроек SHALL NOT происходить.

#### Scenario: Первый запуск
- **WHEN** новый пользователь отправляет `/start`
- **THEN** бот отвечает текстом §7.1, пользователь и его дефолтные настройки созданы, меню показывает «😴 Заснул»

#### Scenario: Повторный запуск
- **WHEN** существующий пользователь отправляет `/start`
- **THEN** бот отвечает текстом §7.1, настройки и события пользователя не сбрасываются
