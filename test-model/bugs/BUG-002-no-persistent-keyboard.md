# BUG-002: нет постоянной клавиатуры — после диалога нечем нажимать

- **Дата:** 2026-10-28
- **Источник:** живая приемка Марии («кнопки не доступны на постоянной основе»,
  «не могу еще раз ничего ввести»)
- **Severity:** S2 (блокирует повседневное использование)
- **incident_ref:** S2-20261026-no-persistent-keyboard

## Симптом

Меню — inline-кнопки внутри конкретного сообщения. После завершения диалога
и новых сообщений клавиатура остается в истории чата: прокручивать и искать —
невозможно. Ввести новое событие нечем.

## Root cause

В 2.3 меню унифицировано на inline-клавиатуре; постоянная reply-клавиатура
(панель внизу экрана) из 2.1 была заглушкой и убрана. D5-guard делает
статичную клавиатуру безопасной (состояние проверяется на нажатии), но
постоянной панели нет.

## Решение (санкционировано ПМ)

- Постоянная reply-клавиатура внизу экрана: [😴 Заснул] [☀️ Проснулся]
  [↩️ Отменить] — видна всегда, не зависит от сообщений.
- Нажатие «не той» кнопки — не ошибка: guard перечитывает состояние и отвечает
  по факту («уже спит» / «еще бодрствует»), inline-меню дублирует в чат.
- Дополнительно: после каждого события бот присылает свежее меню-сообщение.
- Ответ на press обрабатывается текстом кнопки (ReplyKeyboard присылает текст).
