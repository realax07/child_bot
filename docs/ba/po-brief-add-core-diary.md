## 1. Цель пакета

Рабочий дневник сна без подсказок: родитель отмечает «Заснул»/«Проснулся» (в т.ч. задним числом), бот корректно хранит события, размечает день/ночь, склеивает короткие пробуждения и показывает подтверждения. Подсказки окон (Пакет 2) — вне скоупа, кроме текстов подтверждений, где окно уже упоминается в ТЗ (см. п. 5).

## 4. Приемочные критерии (проверяемые)

### AC-1. Переключение состояний
- После /start ребёнок считается бодрствующим; меню показывает «😴 Заснул».
- Нажатие «😴 Заснул» → создаётся событие засыпания, меню меняется на «☀️ Проснулся», ответ по §7.5.
- Повторное нажатие той же кнопки невозможно (меню динамическое).

### AC-2. Разметка день/ночь
- Сон с началом ≥ 19:00 или концом ≤ 07:00 размечен как ночной, иначе дневной.
- Начало 18:50 → дневной + предупреждение §4.2 («Поздний дневной сон может сдвинуть ночной»).
- Начало 19:30 и длительность < 40 мин → метка «требует проверки» (в данных; текст вывода — Пакет 2).

### AC-3. Склейка
- Пробуждение короче 20 мин внутри сна → интервалы объединяются, короткое пробуждение не создаёт отдельного периода бодрствования.
- Порог берётся из settings (по умолчанию 20 мин), расчёт на лету из сырых событий (ТЗ §9.5).

### AC-4. Ввод задним числом
- Кнопки «🕐 Сейчас» / «⏪ Ввести время вручную» после каждого события-кнопки.
- Принимаются форматы `10:50`, `вчера 22:30`, `08.10 7:15`; неверный формат → §7.12 с повторным запросом.
- Событие старше 3 дней → §7.15, запись не создаётся.
- Конфликт с существующим событием → §7.13 с выбором [Изменить]/[Отменить]; «Изменить» перезаписывает корректно.
- После успешного ввода — §7.14 с обновлённой сводкой за день (без окон: окна добавит Пакет 2; в пакете 1 в сводке — суммарные сон/бодрствование). **Interpretation note:** ТЗ §7.14 упоминает окно дневного сна — на пакет 1 оставляем только цифры, окно скроем до Пакета 2. Подтвердить.

### AC-5. Данные и часовой пояс
- Схема: users, sleep_events, settings (SQLite, WAL); события неизменяемы по факту, правка — новая запись/перезапись по AC-4.
- TZ сохраняется при /start из TG-профиля; все времена ввода/вывода — в TZ пользователя.
- Дефолтные 12 параметров настроек создаются при /start.

### AC-6. Тексты
- /start, подтверждения «Проснулся»/«Заснул», ошибки ввода — дословно по §7.1–7.5, §7.10–7.15 (с оговоркой AC-4 про окна).

## 5. Приоритеты
