## Технические (найдены при ревью)

**ОВ-М1. Целевая длительность дневного сна.**
В текстах бота есть прогноз «ожидаемое пробуждение около 15:00» (7.7), но параметра в настройках нет (только крайнее 15:30). Предлагаю добавить в настройки «Целевая длительность дневного сна» = 1 ч 30 мин (из эталона 3.5: 13:30→15:00). Согласны? Если да — прогноз = старт сна + цель, но не позже 15:30.

**ОВ-М2. Ночь и граница дня.**
«Начало дня: 06:00», но ночной сон длится «до 07:00». Ночь 22:10→07:20 — бодрствование какой даты считает? Предлагаю правило: вся ночь атрибутируется дню её НАЧАЛА (22:10 → «вчера»). Подтвердить/поправить.

**ОВ-М3. Правка отдельного события.**
Сейчас в UI только `/delete_all`. В API удаление события есть. Нужна ли кнопка «исправить последнее событие» (удалить/переввести)? По опыту дьярников — понадобится в первые же дни (промах по кнопке). Предлагаю: да, минимально «↩️ Отменить последнее».

**ОВ-М4. «Вчера» при начале дня 06:00.**
«Вчера 05:00» — по правилам бота это уже «сегодня» (до 07:00 — ночь). Как трактовать ввод? Предлагаю: парсер считает «вчера» = предыдущая календарная дата, а не «до начала дня»; конфликтные времена бот помечает предупреждением.
