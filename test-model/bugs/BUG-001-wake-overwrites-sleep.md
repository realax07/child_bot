# BUG-001: backfill wake стирает запись о засыпании (перезапись вместо пары)

- **Дата:** 2026-10-26
- **Источник:** живая приемка Марии, бот @pers_child_schedule_bot
- **Severity:** S2 (некорректная перезапись данных пользователя, использование заблокировано)
- **incident_ref:** S2-20261026-wake-overwrites-sleep

## Симптом

Засыпание записано (задним числом). Родитель вводит задним числом «когда проснулся».
Бот показывает §7.13 (конфликт), родитель жмёт «Изменить» → запись о засыпании
ЗАМЕНЯЕТСЯ событием wake. Сводка: «Сон: 0 мин. Бодрствование: 24 ч».
Сон и бодрствование меняются местами — пользоваться нельзя.

## Root cause (гипотеза ПМ — проверит dev)

detect_conflict трактует ЛЮБОЙ wake после sleep как «нарушение порядка» → конфликт →
предлагает перезапись. Но wake ПОСЛЕ незакрытого sleep — это штатное закрытие интервала
(пара), ровно как парные кнопки §4.1. Конфликт — только wake РАНЬШЕ начала сна
или внутрь уже закрытой пары. Выбор цели по D11 («последнее нарушающее») при этом
стирает именно сон.

## Требуемое поведение

- Последнее событие = sleep, ввод wake ≥ sleep.start → штатное создание wake-события
  (закрывает интервал), БЕЗ §7.13.
- Конфликт: wake раньше sleep.start; точное совпадение; пересечение с закрытой парой —
  §7.13 как раньше (D11 для настоящих конфликтов сохраняется).

## Компенсация данных Марии

Перезаписанный сон не восстановим автоматически (нет soft-delete) — повторный ввод
задним числом после фикса.
